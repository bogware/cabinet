    Settings
    How this Cabinet server behaves
    
                    
    
                        
                    
    
                
    
                
    
                    
    
                    
    
                        
    
                        
    

                        
    
                        
    
                            
    Loading…
    
                            
    
                            
    
                                
    Moving copies your events, settings, rules, keys and history. The database in use now is never changed or deleted by a move.
    
                                
    
                                    
    Move to another folder or drive
    
                                    
    Copies the database file whole: events, settings, rules, keys and history. New events wait a few seconds while it copies, then Cabinet restarts on the new file. The old file stays where it is until you delete it.
    
                                    
                                    
    
                                        
                                        
                                    
    
                                    
    
                                
    

                                
    
                                    
    Switch to the Cabinet engine
    
                                    
    Cabinet's own storage: much faster searches and aggregates on one server, a fraction of the disk, and no database to run. Events, settings, rules, keys and history are copied while Cabinet keeps running; at the end new events wait a few seconds for the switch. The current database is kept, so you can switch back.
    
                                    
                                    
    
                                        
                                        
                                    
    
                                    
    
                                
    

                                
    
                                    
    Switch to PostgreSQL
    
                                    
    Faster searches and aggregates on large volumes, and room for more than one Cabinet server. Everything is copied while Cabinet keeps running; at the end new events wait a few seconds for the switch.
    
                                    
    
                                        
                                        
                                        
                                        
                                        
                                        
                                    
    
                                    
    Or paste a connection string
                                        
                                    
    
                                    
                                    
                                    
    
                                        
                                        
                                    
    
                                    
    
                                    
    No PostgreSQL yet? On this server, run the installer with -Storage postgresql to install one locally.
    
                                
    

                                
    
                                    
    Start a new, empty database
    
                                    
    Cabinet starts over with no events, and none of the rules, keys, saved searches or history made in the dashboard. Settings saved on these pages and keys from the installer stay. The current database is kept, so you can switch back to it.

A key is shown once, when it's created.
